¿Qué es un arreglo?

Antes de programar, necesitamos comprender la idea. Un arreglo es mucho más que una lista: es una estructura con reglas precisas sobre cómo se organiza la memoria. El concepto es idéntico en JavaScript y en C++, aunque la sintaxis y la gestión de memoria difieran.

Un arreglo es una colección finita, homogénea y ordenada de elementos del mismo tipo. Cada elemento ocupa una posición identificada por un índice que comienza en cero.
A = [ a₀ , a₁ , a₂ , ... , aₙ₋₁ ]  |  índice ∈ [0, N-1]
C++ int arr[10]; es un arreglo de tamaño fijo real, almacenado en el stack. Y std::vector<int> es la versión encapsulada y dinámica de la STL.

JS El Array nativo es un objeto dinámico (no garantiza memoria contigua). Para arreglos contiguos y de tamaño fijo reales, usa Int32Array, Float64Array u otros TypedArrays.

Características esenciales

Todo arreglo cumple un contrato de diseño. Comprenderlo es el primer paso para usarlo correctamente y, después, para encapsularlo en una clase.

01
Homogeneidad
Todos los elementos son del mismo tipo. En C++ es estricto; en JS, Array lo permite pero Int32Array lo impone.
02
Orden
Los elementos están en secuencia lineal. El índice define exactamente su posición.
03
Tamaño fijo
En C++ int[10] es fijo; en JS, new Array(n) es dinámico — usa new Int32Array(n) para tamaño fijo real.
04
Acceso O(1)
El acceso por índice es constante gracias al cálculo directo de direcciones de memoria.
05
Memoria contigua
En C++ el arreglo es un bloque contiguo. En JS solo los TypedArrays lo garantizan.
06
Índice base 0
Ambos lenguajes indexan desde 0. El último índice válido es N-1.

Las limitaciones del arreglo desnudo

Antes de encapsular, hay que reconocer los problemas del arreglo primitivo. En C++ son más peligrosos (no hay validación), en JS son distintos (no hay tamaño fijo real).

C++

Sin validación de rango

Acceder a arr[10] en int[10] NO lanza excepción: es undefined behavior. Puede leer basura o corromper memoria.

C++

Gestión manual de memoria

Con new[] debes recordar delete[]. Olvidarlo produce memory leaks; liberarlo dos veces, corrupción.

C++

Decaimiento a puntero

Al pasar un arreglo a una función, int arr[] se convierte en int*: el tamaño se pierde.

JS

Array no es contiguo

El Array de JS es un objeto con propiedades numéricas. No garantiza acceso O(1) real salvo en V8 con arrays "packed".

JS

Sin tamaño fijo real

new Array(5) no crea un arreglo fijo: es "sparse" y puede crecer. Solo Int32Array(5) es contiguo y fijo.

AMBOS

Inserción/eliminación costosa

Insertar o eliminar en medio de un arreglo obliga a desplazar N elementos: costo O(N).

// SECCIÓN 06

La solución: encapsular en POO

La programación orientada a objetos no reemplaza a los arreglos: los envuelve. Al esconder el arreglo dentro de una clase, se controla cada acceso. En C++ existe std::vector; en JS, el patrón es envolver un Array (o TypedArray) en una clase con campos privados.

  • Encapsulamiento
    El arreglo pasa a ser private (C++) o campo privado #elementos (JS). Nadie lo toca sin pasar por los métodos.
  • Composición
    La clase tiene un arreglo como parte de su estado interno; no hereda de él.
  • Responsabilidad única
    La clase gestiona la colección; el cliente solo llama a agregar() u obtener().
  • Gestión de recursos
    En C++ el destructor ~Coleccion() libera con delete[]. En JS el GC libera automáticamente.
  • Interfaz controlada
    Se expone lo necesario. La implementación (Array, TypedArray, pointer) queda oculta y puede cambiarse sin romper a los clientes.
class Coleccion<T>
− T[] elementos // C++: T* / JS: #elementos
− int cantidad
− int capacidad
──────────────
+ agregar(T e) : void
+ obtener(int i) : T
+ tamaño() : int
+ contiene(T e) : boolean
− redimensionar() : void
~ Coleccion() // solo C++

Código real, sin adornos

La misma clase Coleccion, implementada en dos lenguajes. Cambia entre pestañas para comparar la sintaxis y las decisiones de gestión de memoria.

Coleccion.js
// Coleccion.js — encapsulamiento con campos privados (ES2022)
class Coleccion {
  #elementos;      // arreglo encapsulado (privado)
  #cantidad;       // elementos realmente guardados

  constructor(capacidadInicial = 4) {
    this.#elementos = new Array(capacidadInicial).fill(null);
    this.#cantidad  = 0;
  }

  agregar(e) {
    if (this.#cantidad === this.#elementos.length) {
      this.#redimensionar();
    }
    this.#elementos[this.#cantidad++] = e;
  }

  obtener(i) {
    if (i < 0 || i >= this.#cantidad) {
      throw new RangeError(`Índice fuera de rango: ${i}`);
    }
    return this.#elementos[i];
  }

  get tamano() { return this.#cantidad; }

  #redimensionar() {
    const nuevo = new Array(this.#elementos.length * 2).fill(null);
    for (let i = 0; i < this.#cantidad; i++) {
      nuevo[i] = this.#elementos[i];
    }
    this.#elementos = nuevo;
  }
}

// Uso:
const c = new Coleccion();
c.agregar(42);
c.agregar(17);
console.log(c.obtener(0));  // 42
console.log(c.tamano);       // 2
// Coleccion.cpp — C++20 con gestión manual de memoria
#include <stdexcept>
#include <algorithm>
#include <string>

template <typename T>
class Coleccion {
private:
    T*  elementos;   // arreglo encapsulado (puntero)
    int cantidad;    // elementos realmente guardados
    int capacidad;   // tamaño reservado

public:
    explicit Coleccion(int cap = 4)
        : elementos(new T[cap]), cantidad(0), capacidad(cap) {}

    ~Coleccion() { delete[] elementos; }        // destructor
    Coleccion(const Coleccion&) = delete;        // sin copia
    Coleccion& operator=(const Coleccion&) = delete;

    void agregar(const T& e) {
        if (cantidad == capacidad) redimensionar();
        elementos[cantidad++] = e;
    }

    T obtener(int i) const {
        if (i < 0 || i >= cantidad)
            throw std::out_of_range("Índice: " + std::to_string(i));
        return elementos[i];
    }

    int tamano() const { return cantidad; }

private:
    void redimensionar() {
        capacidad *= 2;
        T* nuevo = new T[capacidad];
        std::copy(elementos, elementos + cantidad, nuevo);
        delete[] elementos;   // liberar memoria anterior
        elementos = nuevo;
    }
};

// Uso:
int main() {
    Coleccion<int> c;
    c.agregar(42);
    c.agregar(17);
    // c.obtener(0) == 42, c.tamano() == 2
}
